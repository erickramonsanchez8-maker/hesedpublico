# HESED PÚBLICO

Sitio estático de Grupo HESED con tres experiencias integradas en una sola página:

- `index.html`: portal corporativo, experiencia de SHALOM y experiencia de BEFIT.
- `styles.css`: estilos y diseño responsivo.
- `script.js`: navegación y enlaces de contacto por WhatsApp.
- `assets/shalom/`: fotografías propias de Shalom optimizadas para web.

## SHALOM — datos configurados

- Dirección: Av. Calzada Madero y Carranza 498, Ciudad Guzmán, Jalisco, 49000, México.
- Horario: viernes y sábado, de 8:00 a. m. a 2:00 p. m.
- WhatsApp: +52 1 341 107 6050.
- Reservaciones y pedidos a domicilio por WhatsApp.
- Ubicación con enlace e inserción de Google Maps.
- Fotografías propias del interior, terraza, mesa, platillos y bebidas.

## Pendiente antes de considerar la publicación definitiva

- Completar el menú oficial de SHALOM y sus precios.
- Cargar el logotipo original si se entrega como archivo independiente.
- Confirmar los datos de contacto de BEFIT.
- Completar direcciones, horarios y planes oficiales de las dos sedes de BEFIT.
- Sustituir posteriormente las imágenes de stock de HESED y BEFIT con sus respectivas fotografías oficiales.

El sitio no necesita servidor ni base de datos para esta versión estática. Puede publicarse con GitHub Pages o cargarse en el hosting contratado.
