# HESED PÚBLICO

Sitio público de Grupo HESED con tres páginas estáticas:

- `index.html`: presentación corporativa y selector de negocios.
- `shalom.html`: restaurante, menú, galería y contacto/reservación por WhatsApp.
- `befit.html`: dos sedes, información de membresías, instructores, horarios y contacto.

## Configuración antes de publicar

Edita `script.js` y reemplaza los números de WhatsApp de `HESED_CONFIG.whatsapp` por los números oficiales en formato internacional, sin +, espacios ni guiones.

Completa en `shalom.html` los horarios, menú, precios y fotografías oficiales. Completa en `befit.html` direcciones de las dos sedes, tarifas, horarios e información de instructores. Los textos que indican datos por confirmar son intencionales: no se inventaron datos comerciales.

## Publicación

Es un sitio estático: no necesita servidor ni base de datos para esta primera versión. Puede publicarse con GitHub Pages o cargarse en el hosting contratado.
